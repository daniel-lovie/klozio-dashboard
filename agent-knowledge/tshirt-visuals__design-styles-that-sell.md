# Design Styles, Colors, and Typography That Sell

## The Universal Rule

Simple, bold, legible at thumbnail size. Every bestselling t-shirt design on Etsy passes the scroll test: the message or graphic is instantly readable in a 300px thumbnail. Complexity that only reads at full size loses to simplicity that reads everywhere.

## Trend Directions (current)

Retro/vintage dominates: nostalgia themes, distressed textures, vintage fonts, 70s sunset stripes, vintage-postcard national park style. "Sports-core" is rising (pickleball, tennis, golf). "Dopamine dressing" (colorful, happy, playful designs) continues. Retro groovy wavy text is one of the highest-selling text-only styles on the platform.

## Winning Visual Formulas by Niche

| Niche | Formula that sells |
|-------|--------------------|
| Sports | Player silhouettes in action + bold energetic type; retro mascots + distressed texture; vintage script baseball fonts |
| Hobbies | 8-bit pixel art (gaming); book stacks + "one more chapter" (reading); mountain scenes + "Adventure Awaits" (outdoors) |
| Inspirational | Simple text-only modern typography ("Choose Joy"); hand-lettered scripture |
| Pets | Custom pet portrait personalization (cartoon/watercolor from buyer's photo + pet name); cute illustration + relatable saying |
| Travel | Retro travel-poster art; city skylines + bold lettering; state outlines filled with icons; rustic camp typography |
| Music/nostalgia | Lyric quote + era imagery (e.g., desert highway graphic + "On a Dark Desert Highway" was a documented bestseller) |

Evergreen high-demand niches: pets, travel, food, sports, music, and niche interests (gaming, books, science). Personalization (names, photos) adds price premium and defensibility.

Match the design aesthetic to the audience: calm colors and zen graphics for yoga buyers, punchy colors and whimsical fonts for funny tees, muted earth tones for the Comfort Colors boho crowd.

## Color Psychology for Shirt + Ink Choices

| Color | Signal | Works for | Strong pairings |
|-------|--------|-----------|-----------------|
| Red | Energy, passion, urgency | Sports, bold statements | White or black ink |
| Orange | Creativity, playfulness | Casual, fitness, youth | Navy, gray |
| Yellow | Happiness, optimism | Summer, cheerful quotes | Black ink on yellow |
| Green | Nature, growth, health | Eco, wellness, outdoors | Dark green + gold; light green + white |
| Blue | Trust, calm | Teams, corporate, dads | Navy = serious; light blue = casual |
| Purple | Luxury, creativity | Premium/feminine designs | Gold accents |
| Black | Power, elegance | Streetwear, band merch, minimalist | Bold white ink |
| White | Clean, modern | Any bright design | Lets colors pop |

Non-negotiable: high contrast between ink and shirt color. Highest-contrast combos: black+white, red+yellow, blue+orange. Audience skew: younger buyers respond to brights; professional/older audiences prefer neutrals and muted garment-dyed tones.

## Typography Guide

Rules: maximum 3 fonts per design (2 is better); pair one bold display font with one clean support font; match the font's personality to the message; ink-vs-shirt contrast must be strong.

| Font | Personality | Best for |
|------|-------------|----------|
| Montserrat | Clean, minimal | Minimalist designs, curved text; uppercase + letter spacing |
| Graduate | Slab-serif athletic | School, sports, collegiate arcs |
| Shrikhand | Bold retro | Groovy designs with reds/blues/yellows |
| Special Elite | Typewriter | Vintage quotes, lowercase for a thoughtful look |
| Sacramento | Elegant script | Feminine designs; pair with spaced sans-serif |
| Amatic SC | Hand-drawn tall | Nature, hiking, outdoorsy themes |
| Abril Fatface | Bold serif display | Statement headlines |
| Permanent Marker | Gritty handwritten | Textured designs, all caps, high contrast |
| Bungee | Urban display | Streetwear |
| Ultra | Heavy slab | Retro shadow layering: stack off-center copies in contrasting colors |
| Caveat Brush | Playful brush | Casual, youthful sayings paired with sketches |

## Design File Requirements

Print file: transparent-background PNG, 300 DPI, ~4500x5400px for POD. Keep the design's line weights and text sizes thick enough to survive both the physical print and the thumbnail shrink. Original artwork only — Etsy requires original designs and disclosure of the POD production partner.
