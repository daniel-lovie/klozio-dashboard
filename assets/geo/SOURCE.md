# us-states.json

Simplified US state boundary polygons, used to raster state silhouettes for the eclipse collection.

- Retrieved 2026-08-17 from `PublicaMundi/MappingAPI` (`data/geojson/us-states.json`).
- Derived from **US Census Bureau TIGER/Line** boundary files, which are works of the US federal
  government and carry no copyright.
- Geometry only. It contains no logo, seal, flag or other state insignia — a state OUTLINE is a
  geographic fact, whereas a state seal or flag is a protected mark and must never be drawn.
